🌰 Ett nytt frö kan gro

Livscykeln visar hur en växt utvecklas. Sedan kan en ny generation börja växa.

Steg 1. Fröet

🌰

Allt börjar med ett frö.

Ett frö innehåller ett litet växtembryo. Embryot kan utvecklas till en ny planta.

Fröet har ofta ett skyddande skal. Det kan också innehålla lagrad näring.

Viktigt: Fröet kan vila innan det börjar gro.

Steg 2. Fröet börjar gro

💧

Fröet tar upp vatten.

Fröet sväller när det tar upp vatten. Då kan groddningen börja.

Fröet behöver också syre. Temperaturen måste vara lämplig.

Kom ihåg: Vatten, syre och rätt temperatur behövs för att många frön ska gro.

Steg 3. Groddplantan växer fram

🌱

En liten rot börjar växa.

Roten växer ofta ut först. Den växer nedåt i jorden.

Sedan växer ett skott uppåt. Skottet kan utveckla blad.

Den unga växten kallas groddplanta.

Steg 4. Plantan växer

🌿

Plantan får fler blad.

Bladen börjar fånga ljus. Växten kan utföra fotosyntes.

Vid fotosyntesen använder växten:

  • ljusenergi
  • vatten
  • koldioxid

Då bildas socker och syre. Sockret hjälper växten att växa.

Lär dig om fotosyntesen

Steg 5. Den vuxna växten

🌻

Växten fortsätter att utvecklas.

Många blomväxter kan nu bilda blommor. Blommorna har viktiga delar för fortplantning.

Pollen kan flyttas mellan blommor. Det kallas pollinering.

Efter pollinering kan befruktning ske. Då kan frön börja utvecklas.

Lär dig om fortplantning

Steg 6. Nya frön bildas

🍎

Frön kan utvecklas efter befruktning.

Hos blomväxter utvecklas fröämnen till frön efter befruktning.

Fruktämnet utvecklas ofta till en frukt. Frukten kan skydda fröna.

Fröna kan sedan spridas till nya platser.

Lär dig om fröspridning

Växten behöver olika saker

Under livet behöver växten flera saker för att kunna utvecklas.

Vatten

Vatten behövs för växtens processer och transport av ämnen.

Ljus

Ljus ger energi till fotosyntesen.

Koldioxid

Koldioxid kommer från luften. Växten använder den vid fotosyntesen.

Mineralämnen

Rötterna tar upp mineralämnen från marken. Växten behöver dem för att växa.

Syre

Fröet behöver syre för cellandning när det börjar gro.
