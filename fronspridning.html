Växter kan inte gå till nya platser. Men deras frön kan flytta sig. Det kallas fröspridning.

Vad är fröspridning?

Fröspridning betyder att frön flyttas från moderplantan.

Moderplantan är växten som bildade fröet. Fröet kan hamna på en ny plats.

Om fröet får rätt förutsättningar kan det gro. Då kan en ny växt börja växa.

Kom ihåg: Fröspridning hjälper växter att nå nya platser.

1. Frön sprids med vinden

🌬️

Vind

Vissa frön är mycket lätta. De kan flyga eller sväva med vinden.

Några frön har små hår eller vingar. Det gör att vinden lättare kan föra dem iväg.

Exempel: Maskrosens frön har små fallskärmsliknande hår. Vinden kan föra dem långt bort.
Fundera: Varför är det bra att ett frö är lätt?

2. Frön sprids med djur

🐾

Djur

Djur kan sprida frön på olika sätt.

Vissa frön har små hakar. De kan fastna i djurens päls.

Andra frön finns inuti frukter. Djur äter frukterna. Frön kan sedan komma ut med spillningen.

Exempel: Kardborrefrön kan fastna i päls och kläder. Fåglar kan sprida frön genom att äta bär.
Kom ihåg: Djur kan transportera frön till nya platser.

3. Frön sprids med vatten

💧

Vatten

Vissa frön och frukter kan flyta. Vattnet kan föra dem till en ny plats.

Frön kan spridas med bäckar, floder och hav.

Exempel: Kokosnötter kan flyta på havet. De kan föras till andra stränder.
Fundera: Vilka egenskaper behöver ett frö ha för att flyta?

4. Växten sprider sina frön själv

🌱

Självspridning

Vissa växter har frukter som öppnas med kraft. Då kan fröna kastas iväg.

Fröna hamnar en bit från moderplantan.

Exempel: Hos vissa arter av nävor och ärtväxter kan frukten öppnas och sprida fröna.
Kom ihåg: Växten behöver inte alltid vind, vatten eller djur.

Varför är fröspridning viktigt?

Om alla frön stannade nära moderplantan skulle många plantor växa mycket nära varandra.

Då kan de behöva dela på ljus, vatten och plats.

Fröspridning kan hjälpa växter att:

  • nå nya platser
  • växa längre bort från moderplantan
  • sprida sig till nya områden
  • minska konkurrensen nära moderplantan
Viktigt: Ett frö behöver också rätt förutsättningar. Det behöver bland annat vatten, syre och lämplig temperatur för att gro.

Sammanfattning

🌬️ Vind – frön flyger eller svävar
🐾 Djur – frön fastnar eller äts
💧 Vatten – frön flyter iväg
🌱 Självspridning – frön kastas iväg

Fröspridning gör att växter kan nå nya platser. Där kan nya plantor börja växa.
